# Canadian AI Funding Opportunities Dataset

## Canonical Metadata Standard for Responsible AI Grant Programs

**Version:** 1.0.0
**Document ID:** WIBC-DS-011
**Status:** Foundational Dataset Specification
**Maintained by:** Women in Blockchain Canada

---

# Purpose

This dataset establishes the canonical metadata structure for documenting Canadian and international funding opportunities relevant to responsible artificial intelligence, blockchain, Web4, cybersecurity, digital identity, advanced manufacturing, health technology, education, sustainability, and public-interest innovation.

Rather than functioning as a static list of grants, this dataset provides a standardized schema that enables funding opportunities to be searched, compared, evaluated, versioned, cited, and integrated into knowledge graphs and AI-assisted research systems.

---

# Dataset Objectives

The dataset supports:

- grant discovery;
- funding comparison;
- eligibility analysis;
- strategic planning;
- partnership development;
- proposal prioritization;
- historical tracking;
- knowledge graph construction;
- AI-assisted grant matching.

---

# Primary Record

Each funding opportunity should be represented as a single structured record.

Each record receives a permanent identifier.

Example:

Funding-ID:
CAN-GRANT-000001

---

# Required Metadata

Each funding record should include:

- Funding Identifier
- Program Name
- Funding Organization
- Country
- Province or Territory (if applicable)
- Funding Category
- Research Domain
- Program Description
- Funding Amount
- Minimum Award
- Maximum Award
- Cost Share Requirement
- Eligible Applicants
- Eligible Partners
- Project Duration
- Opening Date
- Closing Date
- Review Timeline
- Funding Priority Areas
- Evaluation Criteria
- Reporting Requirements
- Intellectual Property Requirements
- Data Requirements
- Official Program URL
- Primary Source Citation
- Repository Version
- Last Verified Date

- Blockchain

- Digital Identity

- Data Governance
- Knowledge Graphs

# Readiness Classification

Funding opportunities should indicate the preferred project maturity level.

Suggested levels include:

- Concept
- Research Planning
- Proposal Ready
- Pilot
- Commercialization
- Scale

Create a continuously maintained, version-controlled, machine-readable funding knowledge base that enables researchers, institutions, governments, nonprofits, and AI systems to identify, evaluate, compare, and prioritize responsible AI funding opportunities using transparent and reproducible metadata.
